# عکس‌یار (PhotoSweep)

اپلیکیشن اندرویدی آفلاین برای پیدا کردن عکس‌های تکراری و شات‌های مشابه در گالری گوشی.

## قابلیت‌های نسخهٔ بهینه‌شده

- فهرست‌کردن عکس‌های قابل‌دسترسی از گالری Android MediaStore؛ هیچ تصویری آپلود نمی‌شود.
- ساخت هش و امتیاز عکس با thumbnail سیستم و چهار کارگر هم‌زمان.
- ذخیرهٔ شاخص عکس‌ها روی گوشی بر اساس شناسه، زمان تغییر و اندازهٔ فایل. در «به‌روزرسانی» عکس‌های بدون تغییر دوباره decode نمی‌شوند؛ عکس حذف‌شده هم از فهرست و شاخص داخلی حذف می‌شود.
- نمایش جداگانهٔ دو تب «تکراری‌ها» و «مشابه‌ها»، با گروه‌های جدا در هر تب و دو عکس در هر ردیف.
- ستاره روی عکس پیشنهادی هر گروه. امتیاز فقط تخمینی است و وضوح، جزئیات، نور، کنتراست، رنگ و ابعاد را می‌سنجد؛ تصمیم حذف با کاربر است.
- حذف با تأیید سیستم Android. بعد از حذف، فهرست از داده‌های حافظه به‌روز می‌شود و اسکن مجدد خودکار انجام نمی‌شود. برای عکس‌های تازه، دکمهٔ به‌روزرسانی را بزنید.
- نوار وضعیت تعداد عکس‌های بررسی‌شده و تعداد موارد استفاده‌شده از cache را نشان می‌دهد.
- اسکن در نسخهٔ فعلی داخل صفحهٔ برنامه انجام می‌شود؛ برای تکمیل اسکن اول برنامه را باز نگه دارید. خروج از صفحه یا توقف فرایند توسط Android ادامهٔ اسکن را تضمین نمی‌کند.

## تشخیص و محدودیت‌ها

«تکراری» در این نسخه یعنی عکس‌هایی با هش تصویری، ابعاد و اندازهٔ فایل برابر؛ «مشابه» یعنی عکس‌هایی با ظاهر نزدیک که زمان ثبت آن‌ها حداکثر ۱۵ دقیقه فاصله دارد. مشابهت با difference hash سریع تشخیص داده می‌شود و مدل هوش مصنوعیِ تشخیص صحنه نیست. ستاره نیز یک امتیاز تقریبی است، نه تضمین اینکه آن عکس از نظر انسانی بهترین است. قبل از حذف، تصاویر را بررسی کنید.

این نسخه عکس‌ها را بررسی می‌کند، نه همهٔ فایل‌های گوشی؛ ویدیو، PDF، فایل‌های صوتی، پوشه‌های خصوصی برنامه‌ها و فایل‌های خارج از MediaStore پشتیبانی نمی‌شوند. برای دسترسی کامل به گالری، در Android 14 و بالاتر مجوز کامل عکس‌ها را بدهید؛ با دسترسی محدود، فقط عکس‌های انتخاب‌شده بررسی می‌شوند.

## ساخت APK آنلاین با GitHub Actions

فایل `.github/workflows/build-apk.yml` پروژه را در GitHub Actions می‌سازد. پس از push روی شاخهٔ `main` یا `master`، اجرای خودکار آغاز می‌شود.

1. پوشهٔ `PhotoSweep` را در VS Code باز کنید.
2. در **Source Control** فایل‌های تغییرکرده را commit کنید و **Sync/Push** را بزنید.
3. در مخزن GitHub وارد تب **Actions** شوید و اجرای سبزرنگ **Build Android APK** را باز کنید.
4. از پایین صفحه در بخش **Artifacts** فایل **PhotoSweep-debug-APK** را دانلود و استخراج کنید.
5. فایل `app-debug.apk` را به گوشی منتقل و نصب کنید. اگر اندروید خواست، نصب از WhatsApp یا فایل‌منیجر را مجاز کنید.

نام برنامه «عکس‌یار» و نسخهٔ این ساخت 1.1 است. شناسهٔ برنامه ثابت مانده و شمارهٔ نسخه افزایش یافته است. فایل Artifact همچنان APK کامل است، نه بستهٔ patch؛ Android در صورت یکسان‌بودن کلید امضا آن را روی نسخهٔ قبلی به‌روزرسانی می‌کند. Workflow کلید debug را در cache نگه می‌دارد تا ساخت‌های بعدی همان امضا را استفاده کنند. اگر گوشی خطای ناسازگاری امضا داد، نسخهٔ قبلی را یک‌بار حذف و APK تازه را نصب کنید.

برای پروژه Android Gradle Plugin 8.7.3 از Gradle 8.9 و Java 17 استفاده می‌شود.
