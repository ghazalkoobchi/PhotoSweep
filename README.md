# پاک‌عکس (PhotoSweep)

اپلیکیشن اندرویدی آفلاین برای پیدا کردن عکس‌های تکراری و شات‌های شبیه به هم در گالری گوشی.

## ساخت APK آنلاین با GitHub Actions

فایل `.github/workflows/build-apk.yml` به پروژه اضافه شده است. بعد از اینکه پروژه را در GitHub قرار دهید، هر بار که روی شاخهٔ `main` یا `master` تغییرات بفرستید، GitHub Actions نسخهٔ آزمایشی APK را می‌سازد. از تب Actions هم می‌توانید ساخت را دستی اجرا کنید.

1. فایل `PhotoSweep.zip` را از خروجی این گفتگو دانلود و در یک پوشه استخراج کنید.
2. پوشهٔ استخراج‌شده را در VS Code باز کنید: **File > Open Folder**.
3. از نوار کناری، **Source Control** را انتخاب کنید و **Initialize Repository** را بزنید.
4. پیام commit مثل `Add PhotoSweep app` را وارد و **Commit** را بزنید. اگر VS Code گزینهٔ **Publish to GitHub** را نشان داد، آن را انتخاب کنید، با GitHub وارد شوید و مخزن را **Private** بسازید. اگر قبلاً مخزن را در GitHub ساخته‌اید، از **Publish Branch** یا **Add Remote** استفاده کنید.
5. پس از انتشار، در صفحهٔ مخزن GitHub تب **Actions** را باز کنید. اگر پیام تأیید فعال‌سازی Actions آمد، **I understand my workflows, go ahead and enable them** را انتخاب کنید.
6. اجرای **Build Android APK** را باز کنید و منتظر تیک سبز بمانید. اگر قرمز شد، وارد اجرا شوید و بخش **Build debug APK** را باز کنید تا خطا مشخص شود.
7. اجرای موفق را باز کنید، پایین صفحه در بخش **Artifacts** روی **PhotoSweep-debug-APK** بزنید و فایل ZIP دانلودشده را استخراج کنید. داخل آن `app-debug.apk` قرار دارد.
8. APK را به گوشی منتقل و باز کنید. اگر اندروید اجازه خواست، نصب از همان منبع (مرورگر یا فایل‌منیجر) را مجاز کنید.

مخزن خصوصی برای پروژه‌ای که عکس‌ها را روی دستگاه پردازش می‌کند انتخاب مناسبی است. APK در این روش از سورس مخزن شما ساخته می‌شود؛ خود عکس‌های گوشی وارد GitHub نمی‌شوند. Artifact هر اجرای موفق ۱۴ روز نگه داشته می‌شود.

## ساخت و نصب محلی با Android Studio

1. پوشهٔ `PhotoSweep` را در Android Studio باز کنید.
2. اجازه دهید Gradle همگام‌سازی شود (JDK 17 و Android SDK 35 لازم است).
3. گوشی اندروید را با USB وصل کنید و USB debugging را فعال کنید، یا APK را از مسیر Build > Build APK(s) بسازید و روی گوشی نصب کنید.

حداقل نسخهٔ اندروید Android 11 است. در Android 14 و بالاتر، اگر دسترسی محدود به عکس‌های انتخابی داده شود، فقط همان عکس‌های مجاز بررسی می‌شوند؛ برای بررسی کامل گالری دسترسی کامل عکس‌ها را انتخاب کنید.

## روش تشخیص و محدودیت

اپ از difference hash روی تصویر کوچک‌شده استفاده می‌کند؛ عکس‌هایی که اختلاف هش آن‌ها حداکثر ۷ بیت باشد و زمان ثبتشان حداکثر ۱۵ دقیقه فاصله داشته باشد، در یک گروه قرار می‌گیرند. این روش برای شات‌های پشت‌سرهم مناسب است اما تشخیص هوشمند صحنه با مدل بینایی نیست، پس ممکن است مورد مشابهی جا بماند یا عکس‌های مشابه اشتباه کنار هم قرار گیرند. پیش از حذف، تصویر و نام هر فایل را بررسی کنید. هیچ فایلی بدون انتخاب شما حذف نمی‌شود.

## حریم خصوصی

تصاویر روی گوشی بررسی می‌شوند و هیچ عکسی آپلود نمی‌شود. GitHub Actions فقط سورس برنامه را می‌سازد و فایل APK تولیدشده را به‌عنوان Artifact نگه می‌دارد.
