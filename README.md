# Duplio

اپلیکیشن اندرویدی آفلاین برای یافتن عکس‌های تکراری و شات‌های مشابه در گالری.

## قابلیت‌ها

- بررسی عکس‌های قابل‌دسترسی از Android MediaStore؛ تصاویر به اینترنت آپلود نمی‌شوند.
- پردازش thumbnail با چهار کارگر هم‌زمان و cache محلی؛ در به‌روزرسانی فقط عکس‌های تازه/تغییرکرده دوباره decode می‌شوند.
- تب‌های جداگانهٔ «تکراری‌ها» و «مشابه‌ها»، گروه‌بندی و دو عکس در هر ردیف.
- ستارهٔ پیشنهاد کیفیت برای هر گروه؛ حذف فقط با انتخاب کاربر و تأیید Android.
- نتیجهٔ به‌روزرسانی شمار عکس‌های تازه، استفاده از cache، تعداد گروه‌ها و عکس‌های گروه‌نشده را اعلام می‌کند.
- بعد از حذف، فهرست در حافظه اصلاح می‌شود و اسکن کامل خودکار شروع نمی‌شود.
- اسکن در صفحهٔ برنامه انجام می‌شود؛ برای تکمیل آن برنامه را باز نگه دارید.

## محدودیت تشخیص

«تکراری» بر اساس هش‌های تصویری و ابعاد برابر گروه‌بندی می‌شود. «مشابه» بر اساس هش‌های تصویری نزدیک، با درنظرگرفتن زمان ثبت عکس‌های پشت‌سرهم، گروه‌بندی می‌شود. این روش آفلاین و سریع است اما مدل هوش مصنوعی تشخیص صحنه نیست؛ ستاره هم پیشنهاد تقریبی است. پیش از حذف، عکس‌ها را بازبینی کنید.

این نسخه عکس‌های گالری را می‌خواند، نه همهٔ فایل‌های گوشی؛ PDF، ویدیو، فایل صوتی و پوشه‌های خصوصی پشتیبانی نمی‌شوند.

## نسخه و به‌روزرسانی

نام برنامه **Duplio** است. نسخهٔ این ساخت 1.3 با `versionCode` برابر 4 است. Artifact یک APK کامل است، نه patch. نصب به‌عنوان به‌روزرسانی درجا به application ID یکسان، گواهی امضای یکسان و versionCode جدیدتر نیاز دارد. [شرایط رسمی به‌روزرسانی اندروید](https://developer.android.com/google/play/app-updates)

Workflow ابتدا از debug keystore ذخیره‌شده در GitHub Actions cache استفاده می‌کند و یک نسخهٔ پشتیبان خصوصی از آن را به‌صورت Artifact می‌سازد. آن Artifact را با دیگران به‌اشتراک نگذارید. پس از ساخت موفق، برای پایداری بلندمدت:

1. Artifact با نام **Duplio-SIGNING-KEY-PRIVATE** را دانلود و استخراج کنید.
2. در پوشهٔ استخراج‌شده PowerShell را باز کنید و این دستور را اجرا کنید تا keystore به Base64 تبدیل و در Clipboard کپی شود:

   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes(".\debug.keystore")) | Set-Clipboard
   ```

3. در GitHub به **Settings > Secrets and variables > Actions > New repository secret** بروید. نام Secret را `ANDROID_KEYSTORE_BASE64` بگذارید و مقدار Clipboard را وارد کنید.
4. فایل keystore اصلی را هم در جایی امن نگه دارید. بعد از تنظیم Secret، اجرای‌های بعدی همان کلید را از Secret می‌گیرند.

نسخه‌های خیلی اولیه که قبل از ذخیره‌شدن کلید ساخته شدند ممکن است امضای دیگری داشته باشند. اگر کلید خصوصی آن APK در دسترس نباشد، Android به‌روزرسانی درجا را نمی‌پذیرد و برای مهاجرت از آن نسخه باید یک بار نصب قبلی حذف شود. پس از مهاجرت به کلید ثابت، versionCode را در هر انتشار افزایش دهید و دیگر کلید امضا را عوض نکنید.

## ساخت APK آنلاین

پس از commit و push روی `main`، در تب **Actions** اجرای موفق **Build Android APK** را باز کنید. از بخش **Artifacts**، `Duplio-debug-APK` را دانلود و استخراج کنید؛ `app-debug.apk` فایل نصب است.
